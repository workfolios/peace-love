# Peace Love Home + Pet Watch

Exact GitHub Pages mirror of the completed Google AI Studio website and application prototype.

Public site: https://workfolios.github.io/peace-love/

## Governing Standard

The original Google AI Studio source export and the supplied desktop-view and mobile-view screenshot records are the design and content authorities. The GitHub deployment preserves the approved copy, layout, visual rhythm, color palette, typography, CTA strategy, responsive behavior, and application interfaces.

## Included Application Views

- Home
- House Watch
- Drop-In Pet Care
- Vacation-block request flow
- Client Portal
- Staff Admin Portal
- Prairie Land Reserve Associate Portal
- Testimonial submission and moderation demonstrations
- Browser-side calendars, calculators, notifications, printing, downloads, and local-state interactions

## Technical Boundary

The complete interface is preserved for portfolio demonstration. Browser-local interactions are not a substitute for secure authentication, a shared database, protected document storage, payment processing, email delivery, SMS delivery, backups, audit logging, or server-side authorization.

See `docs/GITHUB_PORTFOLIO_MIRROR_TECHNICAL_MEMO.txt` and `docs/VISUAL_FIDELITY_STANDARD.txt`.
